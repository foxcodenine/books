# HTML & CSS: Design and Build Websites

Personal practice exercises for *HTML & CSS: Design and Build Websites* by Jon Duckett.

## Layout

Each `chapter-XX` directory contains the exercises for that chapter. The directories use two-digit chapter numbers so they sort in reading order.

## Earlier work

An earlier pass through the book, together with reference material, is preserved at [`../html-css-design-and-build-websites-first-pass`](../html-css-design-and-build-websites-first-pass). It is kept separately because some early exercises contain different attempts at the same examples.
